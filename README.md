# Chatbot de Atendimento

Projeto desenvolvido para a disciplina de Algoritmos e Pensamento Computacional.

## Descricao

Simula um atendimento virtual com menu interativo, permitindo ao usuario escolher entre os setores Suporte, Financeiro, Comercial ou falar com um atendente. Ao final, exibe um resumo dos atendimentos realizados.

## Funcionalidades

- Menu interativo com laco de repeticao
- Processamento das opcoes com switch
- Contagem de acessos por setor
- Validacao de entradas invalidas
- Analise final do volume de atendimentos

## Tecnologias

- Linguagem C
- GCC (compilador)

## Como compilar e executar

gcc chatbot.c -o chatbot
./chatbot
